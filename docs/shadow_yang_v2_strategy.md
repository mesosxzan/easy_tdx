## 策略概述

本策略是一个**量价配合 + 均线趋势**的中短线交易策略，核心思路是：

1. **买入**：在阴线回调后出现阳线反转时进场，或在均线多头排列首次形成时捕捉主升浪起点。
2. **卖出**：以 ATR 硬止损为底线，辅以分阶段追踪止盈、动态阴线止损、均线止损等多层保护，让趋势单跑起来的同时在风险失控时快速离场。

### 设计理念

| 维度 | 原始版本 (shadow_yang.py) | V2 优化版 |
|------|--------------------------|-----------|
| **持仓周期** | 短线（1-5 天，第一日减半） | 中线（让趋势跑，浮盈越大追踪越宽） |
| **卖出敏感度** | 高（阴线即卖、第一日下跌清仓） | 分层（硬止损 → 追踪止盈 → 均线止损） |
| **仓位管理** | 半仓逻辑（fixed 模式） | 全仓进出（full/fixed 均可） |
| **趋势过滤** | MA20 单一过滤 | MA20 + MA60 方向 + ADX 震荡市 |
| **追高保护** | 无 | 偏离 MA20 + 近期涨幅双重保护 |
| **主升浪捕捉** | 仅依赖"前日阴线"形态 | 新增多头排列首次形成信号 |

## 策略架构

### 状态机

```
WAITING --买入--> HOLDING --止损/止盈--> WAITING
```

简化为两态设计（移除原始版本的半仓状态），全仓进出。

### 指标体系

| 指标 | 周期 | 用途 |
|------|------|------|
| MA5 | 5 日 | 短期趋势、急涨止损线 |
| MA10 | 10 日 | 缓涨止损线、粘合判断 |
| MA20 | 20 日 | 趋势过滤线、追高基准 |
| MA60 | 60 日 | 中长期趋势方向过滤 |
| ATR | 14 日 | 动态止损宽度计算 |
| ADX / +DI / -DI | 14 日 | 趋势强度判断、震荡市识别 |

### 每日执行流程

```
每根 K 线触发 next()：

├─ 空仓 (WAITING)
│   └─ _check_buy() → 检查买入信号 + 过滤条件
│
└─ 持仓 (HOLDING)
    ├─ 更新追踪状态（持仓天数、最高价）
    └─ _check_sell() → 按优先级检查卖出条件
         ├─ A. ATR 硬止损
         ├─ B. 最大亏损保护 (8%)
         ├─ C. 分阶段追踪止盈
         ├─ G. 震荡市时间止损
         ├─ 多头排列 → 均线止损 + 卖出确认
         └─ 非多头排列 → 低开/阴线止损
```

## 买入策略

买入逻辑在 `_check_buy()` 方法中实现，包含 **3 类买入信号** 和 **9 层过滤条件**。

### 买入信号一：影线后收阳

这是原始策略的核心信号，在阴线回调后出现阳线反转时买入。

**条件（全部满足）：**

| # | 条件 | 说明 |
|---|------|------|
| 1 | 当日收阳线 | `close > open` |
| 2 | MA 条件满足 | MA5 上行 **或** 出现标准反转形态（见下） |
| 3 | 收盘价 > 前日最低价 | `close > prev_low`，确认多头承接力 |
| 4 | 前日收阴线 | `prev_close < prev_open` |
| 5 | 前日阴线无长上影线 | 上影 ≤ 实体 × 1.5（强趋势时放宽到 × 2.0） |
| 6 | 非空头强趋势 | 前日 -DI < +DI × 2.0（回调反转买入除外） |

**标准反转形态（MA5 下行时作为替代信号）：**

| 形态 | 条件 | 图示 |
|------|------|------|
| **刺透形态** | 开盘 < 前日最低价，收盘 > 前日实体中点但 < 前日开盘 | `阴▌ ▏阳▎` |
| **看涨吞没** | 当日阳线实体完全覆盖前日阴线实体 | `阴▌ 阳█` |
| **启明星** | 大阴线 + 小实体星线（在阴线之下）+ 阳线收盘深入阴线实体 | `阴█ ▏ 阳▎` |
| **强势反转阳线** | 收盘 ≥ 前日开盘，实体 ≥ 前日阴线实体 × 2.0 | `阴▌ 阳██` |

### 买入信号二：回调反转买入

当股价跌破 MA20 但仍在 MA60 之上时，出现强势反转阳线允许买入，捕捉 MA20 附近的回调反转机会。

**条件（全部满足）：**

| # | 条件 | 说明 |
|---|------|------|
| 1 | 收盘价 < MA20 | 股价在中期均线下方 |
| 2 | 收盘价 > MA60 | 中长期趋势仍向上 |
| 3 | 强势反转阳线 | 实体 ≥ 前日阴线 × 2.0（不接受单纯看涨吞没） |
| 4 | MA20 走平或上行 | `ma20_now >= ma20_prev`，避免下跌中继抄底 |

> **设计依据**：回测诊断显示，看涨吞没在 MA20 下方回调场景中假信号率更高（002407 亏损 -9.3%），而强势反转阳线可靠性更高（600206 微赚 +1.7%）。

### 买入信号三：多头排列首次形成

**新增信号**，不依赖"前日阴线"形态，在均线多头排列首次形成时买入，捕捉主升浪起点。

**条件：**

```
今日满足多头排列 且 昨日不满足多头排列
```

**多头排列定义：**

```
MA5 > MA20 > MA60  且  MA10 > MA20 > MA60
```

若 MA5 < MA10，偏离不超过 1%（`MA5 >= MA10 × 0.99`）。

> **设计依据**：600539 诊断发现，主升浪期间大量连续阳线无"前日阴线"形态，策略完全错过。该信号回测胜率 57.1%，平均收益 6.96%（正期望）。600539 收益从 -8.27% 提升到 +4.83%。

### 过滤条件

所有买入信号共享以下过滤条件，按执行顺序排列。任一过滤触发即放弃买入。

#### 1. 波动率过滤

```
ATR / 收盘价 × 100 > 8%  →  不买入
```

波动过大的股票风险难以控制。

#### 2. 趋势过滤

- **默认**：收盘价须在 MA20 之上
- **例外**：回调反转买入（信号二）允许收盘价 < MA20，但须满足额外条件

#### 3. MA60 趋势方向过滤

```
MA60 近 20 日跌幅 > 0.5%  →  不买入
```

MA60 下行 = 中长期下跌趋势，避免抄底下跌中继反弹。

> **设计依据**：2022 熊市回测 6 笔全亏，根因是 MA20 过滤不足以阻挡下跌中继。

#### 4. ADX 震荡市过滤

```
ADX < 20  且  ADX 下行  且  MA20 下行  →  不买入
```

三重条件判断真正的无方向震荡市。价格已站上 MA20 时此过滤不生效（趋势已确认，ADX 低位只是新趋势起步）。

#### 5. 追高保护 — 偏离 MA20

| 状态 | 偏离上限 |
|------|---------|
| 正常 | 25% |
| 强趋势（ADX≥30 且 +DI>-DI） | 35% |

```
(收盘价 - MA20) / MA20 > 偏离上限  →  不买入
```

#### 6. 追高保护 — 近 5 日涨幅

| 状态 | 涨幅上限 |
|------|---------|
| 正常 | 20% |
| 强趋势 | 30% |

#### 7. 追高保护 — 近 3 日涨幅

| 状态 | 涨幅上限 |
|------|---------|
| 正常 | 12% |
| 强趋势 | 18% |

> **设计依据**：002407 主升浪起飞阶段连续阳线被追高保护过滤阻断，但此时 ADX=53.9（强趋势），高涨幅是趋势延续而非冲顶。

#### 8. 成交量确认

```
当日成交量 < 5 日均量 × 1.0  →  不买入
```

#### 9. 急跌弱反弹过滤

```
前 2 日累计跌幅 > 6%  且  当日阳线实体 < 前日阴线实体 × 0.5  →  不买入
```

急跌后弱反弹说明下跌趋势未结束。

## 卖出策略

卖出逻辑在 `_check_sell()` 方法中实现，按优先级从高到低检查。**任一条件触发即卖出，后续条件不再检查。**

### A. ATR 硬止损

**底线保护，立即执行，无需确认。**

| 市场状态 | 止损倍数 | 止损价 |
|---------|---------|--------|
| 震荡市（ADX < 20） | 1.5 × ATR | `entry_price - 1.5 × ATR` |
| 趋势市（ADX ≥ 20） | 2.2 × ATR | `entry_price - 2.2 × ATR` |

```
收盘价 ≤ 止损价  →  以收盘价止损清仓
```

震荡市收紧硬止损（无方向市场中宽止损无意义，快速认错）。

### B. 最大亏损保护

```
亏损幅度 ≥ 8%  →  以收盘价强制止损清仓
```

无论任何条件，亏损超过 8% 强制离场。

### C. 分阶段追踪止盈

**核心优化：浮盈越大追踪越宽，让趋势单跑起来。**

追踪止损价 = `持仓最高价 - 追踪宽度`，取 ATR 追踪和百分比追踪的**较宽者**（避免 ATR 过小时追踪过紧）。

#### 趋势市（ADX ≥ 20）

| 浮盈区间 | ATR 倍数 | 百分比追踪 | 策略意图 |
|---------|---------|-----------|---------|
| < 5% | 不启用追踪 | — | 只靠硬止损，给足起飞空间 |
| 5% - 15% | 3.0 × ATR | 12% | 宽追踪，让波动不被震出 |
| ≥ 15% | 2.0 × ATR | 12% | 收紧追踪，锁定大部分利润 |

#### 震荡市（ADX < 20）

| 浮盈区间 | ATR 倍数 | 百分比追踪 | 策略意图 |
|---------|---------|-----------|---------|
| < 3% | 不启用追踪 | — | 只靠硬止损 |
| ≥ 3% | 1.5 × ATR | 4% | 收紧追踪，快速落袋 |

> **设计依据**：回测显示持仓 20 天+胜率 100%，而 0-5 天胜率极低。原 7% 固定追踪太紧，把起飞前的趋势单全震出去。

### G. 震荡市时间止损

```
震荡市（ADX < 20）
  且 非多头排列
  且 持仓 ≥ 3 天
  且 浮盈 < 2%
→ 主动离场
```

震荡市价格来回波动无方向，持仓过久不赚钱说明没有趋势。

> **例外**：多头排列中不触发（趋势已形成，ADX 低只是起步阶段）。

### 多头排列持仓卖出

当持仓处于均线多头排列时，执行以下卖出逻辑：

#### 浮盈 > 10%：放宽止损到 MA20

```
收盘价 < MA20  →  止损清仓
```

浮盈较大时给予更多空间，以 MA20 为止损线而非 MA5/MA10。

#### 浮盈 < 10%：多层止损

**第一层：多头排列动态阴线止损**

| 状态 | ATR 倍数 | 最低百分比 | 阈值 |
|------|---------|-----------|------|
| 强趋势+盈利中 | 2.0 × ATR% | 3.0% | `max(2.0×ATR%, 3.0%)` |
| 多头排列（默认） | 1.5 × ATR% | 2.5% | `max(1.5×ATR%, 2.5%)` |

```
当日阴线跌幅 ≥ 阈值  →  止损清仓
```

> 多头排列中阴线止损比非多头排列放宽（1.5 vs 1.2），因为多头排列是趋势确认，阴线更可能是洗盘而非反转。

**第二层：均线止损**

根据 MA5 斜率角度和 MA5/MA10 粘合状态判断：

| MA5 斜率 | 粘合状态 | 止损条件 |
|---------|---------|---------|
| < 45°（缓涨） | 粘合 | `max(开盘, 收盘) < MA10` |
| < 45°（缓涨） | 非粘合 | `收盘 < MA10` |
| ≥ 45°（急涨） | — | `收盘 < MA5` |
| — | 粘合 + 开盘<MA10 + 收阴 | 触发止损 |

**粘合定义**：`|MA5 - MA10| / MA10 ≤ 2%`

**第三层：卖出确认机制**

多头排列中首次触发卖出信号时，不立即卖出，等待 1 日确认（避免假跌破）：

```
首次 should_sell=True  →  设 pending=True，等待次日
次日 should_sell=True  →  确认，执行卖出
次日 should_sell=False →  清除 pending（修复：避免延迟触发）
```

> **Bug 修复**：原实现中 `should_sell=False` 时未清除 pending，导致首次触发后 pending 永远保持 True，后续任意触发都直接卖出（延迟 N 天的假确认）。

### 非多头排列持仓卖出

当持仓不处于均线多头排列时，执行以下卖出逻辑：

#### 低开止损

```
开盘价 ≤ 前日收盘价 × 0.97（低开 3%）  →  以开盘价止损清仓
```

#### 动态阴线止损

| 状态 | ATR 倍数 | 最低百分比 | 阈值 |
|------|---------|-----------|------|
| 强趋势+价格>MA20+盈利中 | 2.0 × ATR% | 3.0% | `max(2.0×ATR%, 3.0%)` |
| 默认 | 1.2 × ATR% | 2.0% | `max(1.2×ATR%, 2.0%)` |

```
当日阴线跌幅 ≥ 阈值  →  止损清仓
```

> 强趋势放宽仅在**价格站上 MA20 且浮盈为正**时生效。亏损中的阴线更可能是趋势反转，不应放宽。

#### 连续 2 日阴线止损

```
前日收阴 且 当日收阴 且 非强趋势放宽  →  止损清仓
```

> 强趋势放宽时不禁用此规则（主升浪中连续阴线洗盘是正常现象，只靠动态阴线止损阈值保护）。

## 用法

### CLI

```bash
# full 模式（默认，全仓进出）
easy-tdx backtest 600206 --strategy-file strategies/shadow_yang_v2.py --table

# fixed 模式（同样支持，行为一致）
easy-tdx backtest SZ 000001 --strategy-file strategies/shadow_yang_v2.py --position-mode fixed --table
```

### Python API

```python
from easy_tdx.backtest import BacktestEngine
from strategies.shadow_yang_v2 import ShadowYangStrategy

engine = BacktestEngine(
    strategy=ShadowYangStrategy,
    cash=100000,
    position_mode="full",    # full / fixed 均可
    warmup_bars=60,          # MA60 需 60 根 K 线预热
)
result = engine.run(df)
```

### 注意事项

1. **预热数据**：MA60 需要 60 根 K 线预热，建议回测时至少提供 1000 根 K 线。
2. **仓位模式**：全仓进出，`full` 和 `fixed` 模式行为一致（不同于原始 `shadow_yang.py` 必须用 `fixed`）。
3. **适用行情**：适合有明确趋势的股票（单边上涨或震荡上行），不适合暴跌熊市（MA60 过滤会自动回避）。
4. **参数调优**：所有参数均为常量定义在文件头部，可根据标的特性调整。
